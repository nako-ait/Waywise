# 1.2 改动说明（v1.2）

> 在 v1.1 基础上按新反馈改：全局导航、首页气泡 + 底部输入、工作台右侧可互动时间轴。
> 回退：`git checkout v1.1`（更早：`v1.0`）。

## 一、全局大导航

- 新增 `components/AppNav.tsx`，挂在 `App.tsx` 的布局里，**所有页面常驻**：
  - 左：品牌「路书编译师 TripCompiler · 上海」
  - 中：**首页 / 工作台 / 个人** 三个一级导航（当前页深色高亮）
  - 右：分享行程、导入行程、当前账号
- 各页面原来的「← 首页」按钮和重复的分享按钮已移除，页面只保留与本页有关的次级工具条：
  - 工作台：标题 · 账号 · 编译状态 · 保存
  - 详情：标题 · 分组 · 导出长图 · 继续编辑
  - 个人：标题 · 退出登录

## 二、首页

- **AI 输入框沉到页面底部**（固定高度 dock，含快捷词、生成按钮、快捷键 Ctrl/Cmd+Enter）。
- **推荐线路改成上方悬浮气泡**：三条示例线路用圆角气泡散落在标题下方，带轻微上下浮动动画（`--tc-rotate` 控制角度），点一下直接载入并进工作台。
- 最近路书保留在气泡区底部的小胶囊里。

## 三、工作台右侧时间轴（可互动）

每一段现在都能直接改，改完立刻重算整份路书：

1. **逐段换交通方式**：每个「两点之间」的行上有一排小按钮（步行 / 公交 / 地铁 / 打车 / 驾车），
   当前方式深色高亮；点另一个 → 写入 `legModes[目的地id]` → 重新编译。
   回酒店那一段独立设置（`legModes["__return__"]`）。
2. **删除地点**：每个站点的右上角「×」把该点从路书里去掉并重算。
3. **添加地点**：列表底部「+ 添加地点」打开弹窗，从本地 276 个 POI 里搜（离线可用），
   选中即加入并重算。
4. 只读场景（详情页、分享落地页）自动隐藏这些操作，只保留导航链接。

### 后端配合

- `PlanRequest` 新增 `legModes: dict[str, str] | None`（目的地 id → 方式，`__return__` 表示回程）。
- `planner._plan_day`：逐段调用 `leg_route(...)` 时用该段自己的方式；`TransportLeg.mode` 与
  `returnLeg.mode` 回传真实方式。
- 说明：**排序**仍按整体方式（矩阵只建一次），**逐段时长/路线**按你选的方式。
  离线模式（无高德 Web 服务 Key）下时长取矩阵估算，切换方式只改路线形状与标签；
  配了 Key 时会按各方式的真实路径规划重算。

### 前端配合

- store：新增 `legModes` + `setLegMode` / `clearLegModes`，并入 plan 指纹（改了就"待重算"）；
  persist 升到 v4；分享快照带上 `legModes`。
- `usePlanController.buildPayload()` 透传 `legModes`（自动剔除已删除地点的覆盖）。
- `routeGeometry` / `MapView`：每段按自己的方式取真实几何，折线不再是一整条同方式路线。
