## 二、现状诊断（为什么需要重排）

| # | 问题 | 具体表现 | 影响 |
| --- | --- | --- | --- |
| D1 | **AI 不是主角** | AI 面板在侧栏最上方，但只是三个小按钮；首屏最显眼的是酒店和演示线路 | 与"AI 规划是核心"的定位冲突，评委第一眼看不到卖点 |
| D2 | **没有主流程** | 打开就是"工作台"，用户要自己摸索：先搜酒店、再加点、再调参数、再点编译 | 首次使用成本高，无法"一句话出结果" |
| D3 | **侧栏 7 个面板堆叠** | 380px 宽、需滚动，编译按钮却在底部另一处 | 视线与操作路径长 |
| D4 | **参数被切碎** | 天数/时间/权重在侧栏，交通方式在底栏，酒店在最上 | 认知负担，"改个方式要跑到底部" |
| D5 | **时间轴挤压地图** | 横排 176px + DayTabs + 底栏 ≈ 290px，地图只剩一半高 | 地图是主视觉却被压缩 |
| D6 | **横排时间轴不适合"路书"** | 站多了要横向滚，无法整体阅读 | 路书本质是"纵向阅读"的文档 |
| D7 | **分享无处安放** | 现在没有任何"路书详情/只读"视图 | 新功能没有落点 |
| D8 | **移动端不可用** | 固定 380px 侧栏 + 横排时间轴 + 底部条 | 分享出去的链接，手机打不开就没意义 |

## 三、分页方案（三选一，待你定）

### 方案 A：单页工作台（最小改动）

保持一页，只重排：AI 提到顶部巨型输入条，侧栏收成 2~3 个折叠组，时间轴改右侧竖排。

- 改动量：中　｜ AI 权重：中　｜ 分享承载：弱（没有详情页，只能用弹窗）
- 适合：时间紧、只想让 AI 更显眼

### 方案 B：首页 + 工作台（两步式）

`/` 首页（AI 入口 + 示例 + 最近路书）→ `/plan` 工作台（地图+参数+时间轴）。

- 改动量：中大　｜ AI 权重：高　｜ 分享承载：中（落地页借工作台只读态）
- 适合：突出"一句话生成"，但没有独立的"路书"实体

### 方案 C（推荐）：首页 + 工作台 + 路书详情/分享落地（三页）

```
/            首页        AI 主入口、示例、我的路书、导入分享
/plan        规划工作台   地图 + AI 对话 + 参数（"正在编辑的草稿"）
/trip/:id    路书详情     只读为主的成稿（可继续编辑）
/s/:code     分享落地     详情页只读态 + 「复制到我的路书」
```

- 改动量：大　｜ AI 权重：高　｜ 分享承载：**强**（`/s/:code` 就是分享页）
- 好处：**"路书"成为一个有 id 的实体**（可保存多份、可分享、可收藏），
  这是分享功能的地基；同时天然解决 D7/D8（详情页可单独做移动端适配）。
- 代价：要引入路由（`react-router`）与多路书存储。

## 四、推荐结构草案（方案 C 的线框）

### 4.1 首页 `/`

```
┌──────────────────────────────────────────────────────┐
│ 路书编译师            [我的路书] [导入分享]            │  ← 极简头
├──────────────────────────────────────────────────────┤
│                                                      │
│        想去哪、玩几天、怎么玩？                         │  ← Hero，占屏 60%
│   ┌────────────────────────────────────────────┐     │
│   │ 带爸妈玩两天，想去朱家角，别太累，住静安寺      │     │
│   └────────────────────────────────────────────┘     │
│               [ 生成我的路书 ]                        │
│                                                      │
│   试试：经典一日 · 浦江夜景 · 水乡两日                 │  ← 三条示例（原 S06）
├──────────────────────────────────────────────────────┤
│  最近的路书（3 份）        导入分享：粘贴链接 / 输口令  │
└──────────────────────────────────────────────────────┘
```

### 4.2 规划工作台 `/plan`

```
┌───────────────────────────────────────────────────────────────┐
│ ← 返回   上海两日草稿           [参数] [分享] [编译路书]        │
├──────────────┬──────────────────────────────┬─────────────────┤
│ AI 对话       │                              │  路书时间轴      │
│ ┌──────────┐ │                              │  Day1 ▾         │
│ │用户：…    │ │                              │  ① 朱家角        │
│ │AI：意图卡 │ │          地  图              │   09:00-11:30   │
│ │  [地点×3] │ │   （标记 + 真实路线 + 箭头）   │   ↓ 公交 42 分   │
│ │  [2 天]   │ │                              │  ② 七宝老街      │
│ │  [编辑]   │ │                              │  …              │
│ ├──────────┤ │                              │                 │
│ │输入框  ↑  │ │                              │  合计：6.4km ¥20 │
│ └──────────┘ │                              │  [为什么这样排]   │
├──────────────┴──────────────────────────────┴─────────────────┤
│ 步行 公交 地铁 打车 驾车   |   候选 12 / 选中 9   |  [重算]      │
└───────────────────────────────────────────────────────────────┘
```

- 左栏 360px：**AI 对话 + 意图卡**（S04 升级）+ 折叠的「酒店/目的地/参数」
- 中间：地图（S12~S17），**最大化**
- 右栏 320px：**竖排时间轴**（S18）+ 日切换（S19）
- 底栏：交通方式 + 统计 + 编译（S20），高度压到 52px

### 4.3 路书详情 / 分享落地 `/trip/:id`、`/s/:code`

```
┌─────────────────────────────────────────────────────┐
│ 上海两日 · 亲子    来自 @张三      [分享][导出长图]    │
├───────────────────────────────┬─────────────────────┤
│                               │ Day 1               │
│         地图（只读）            │ ① 朱家角 09:00-11:30 │
│                               │ ↓ 公交 42 分         │
│                               │ ② 七宝老街 …        │
├───────────────────────────────┴─────────────────────┤
│ 步行 6.4km · 交通 1h44m · ¥20      [复制到我的路书]   │
└─────────────────────────────────────────────────────┘
```

- 只读态与编辑态**复用同一套组件**，一个 `readonly` prop 控制
- 手机上：地图在上、时间轴在下，纵向堆叠
