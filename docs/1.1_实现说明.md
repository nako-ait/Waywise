# 1.1 实现说明（v1.1）

> 基线：1.0（git tag **v1.0**）。本文记录 1.1 做了什么、和拍板清单怎么对应、哪些还没做。
> 回退：`git checkout v1.0`；快照 zip 见 `mockups/99_备份/1.0_备份说明.md`。

## 一、页面与路由

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 首页 | Hero 一句话输入、三条示例线路、最近路书、导入口令、登录/我的、手动规划入口 |
| `/plan` | 工作台 | 左：出发酒店（可折叠）+ 搜索 + 意图卡 + **左下角 AI 对话**；中：地图；右：竖排路书；底部：方式切换 + 统计 + 重算 |
| `/trip/:id` | 路书详情 | 只读为主：地图 + 竖排路书 + 分享 / 导出长图 / 继续编辑 |
| `/s/:code` | 分享落地 | 用口令取回 → **自动编译** → 只读展示 + 「复制到我的路书」 |
| `/me` | 我的 | 本地账号、密钥（掩码）、个人路线库（分组）、我分享过的 |

技术：`react-router-dom` v7（BrowserRouter）。

## 二、核心交互（按你的补充）

1. **首页 A → 工作台 B**：首页只负责"把话说清楚"，点「生成路书」进入工作台，同时把这句话带过去。
2. **第一句话只标点，不编译**：`/api/ai/parse` → 地点立刻出现在地图上（选中态），意图卡同步；
   AI 回一句追问（几天 / 交通），此时右下角路书是"还没有路书"。
3. **后续每句话增量重算**：`/api/ai/replan` → 改天数/方式/权重/时间/去点 → 后端算好整份路书 → 直接渲染。
4. **也可以手动编译**：意图卡底部「编译路书」（参数改了会变成「参数已改，重新编译」）。
5. **AI 对话框固定在左下方**：上部分是地点/意图（可滚动），下部分 300px 固定为对话。

## 五、已知限制（下一步）

1. **账号是本地版**：没有服务端鉴权、没有加密、换设备不同步。真实版需要：用户表 + 登录、密钥加密存储、服务端路书库。
2. **多轮对话没有"撤销上一步"**：目前只能再发一句话改回来。
3. **长图不包含真实地图**：Canvas 手绘的是折线示意图（第三方地图 canvas 拿不到瓦片）；想要真地图截图需要后端出静态图。
4. **`/s/:code` 落地页会自动调用 `/api/plan`**：别人打开分享链接时对方后端必须在线（演示环境 OK）。
5. **分享 payload 不带目的地 id**：导入端（`setFullTripState`）会重新发号；任何直接拿分享数据调 `/api/plan` 的地方都需要补 id（测试页 T1/T2 已踩到）。
