# 1.12 改动说明：把"规则抢答"改成"模型主导 + 工具循环"

## 一、问题

上一版里 `guard` 用正则（`酒店|住宿`）**直接覆盖模型算出来的提案**，所以：
「少走路，6 点前回酒店」里出现"酒店"两个字 → 整句被替换成"我没有酒店房价"。

这不是模型不行，是**代码把模型否决了**。

## 二、v1.12 的结构

```
agent（模型 + 工具循环，最多 3 步）
   ├─ search_pois   查地点（不许凭记忆编地名）
   ├─ preview_plan  用真求解器试算：费用 / 路上时间 / 是否超限
   └─ propose_changes  最终提案（ops + 短回复 + clarify + boundary）
        ↓
verify（只核对"没依据的数字"）
        ↓
END
```

- **意图解析只由模型做**；规则只在"没有 Key / 调用异常"时兜底，并在气泡下标「规则兜底（模型未参与）」；
- `verify` 从"覆盖"改成"核对"：只有当回复里出现**具体金额/星级/温度**、而工具证据里没有对应数字时，才把那几个数字抹掉；
  用户自己给的预算（如"¥150"）和 `preview_plan` 算出来的费用都算有依据，不会被误伤；
- 模型可以主动 `preview_plan` 来回答"够不够/要不要打车"，用真实数字而不是猜。

## 三、新增

| 文件 | 作用 |
