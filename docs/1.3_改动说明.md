# 1.3 改动说明（v1.3）

> 在 v1.2 基础上：修时间轴"点了不高亮"、删掉意图卡、检查账号、加城市选择。
> 回退：`git checkout v1.2`。

## 一、修 Bug：时间轴改交通方式不高亮

**原因**：高亮状态读的是"编译结果里的 `transportFromPrev.mode`"，而点击后要等后端重算回来才更新；
离线模式（没配高德 Web 服务 Key）下重算不改变时长、返回也慢，看起来就像"没选中"。

**改法**：现在以 **store 里的 `legModes`** 为准 —— 点下去立刻变深色，后台再慢慢重算。
回程那一段（`__return__`）同样处理。

## 二、删掉意图卡

- 工作台左栏不再有「意图卡」，与右侧时间轴重复。
- 仍然需要的控件收进**底栏**：交通方式（原有）+ **天数步进器（新增）**。
- AI 对话、搜索、出发酒店保持不变。

## 三、账号登录检查

现状说明（也是"为什么你可能看到未登录"）：

- 这版是**本地账号**：昵称、密钥、路线库都存在**当前浏览器**的 `localStorage`（key `tripcompiler:v1`）。
- 换浏览器、清缓存、换端口（如 5173 → 5180）都会变成未登录。
- 登录入口：右上角头像 / 导航「个人」→ 输入昵称，或点「一键体验登录（本地演示账号）」。
- 登录后：导航右上角显示昵称；个人页显示「已登录（本地）」+ 绿色徽标。
- 已验证：登录 → 刷新 → 仍是登录态；退出 → 回到未登录。
- **没有**服务端账号：不能换设备同步，密钥也未加密（真实版再补）。

## 四、全国城市

- 新增 `data/cities.ts`：**上海 / 北京 / 杭州 / 成都 / 西安 / 广州** 六个城市，
  每个城市带：地图中心、默认酒店、6~8 个地标 POI（坐标是公开地标近似值）、2~3 条推荐线路。
- **首页**：顶部新增「选择城市」一排按钮；选完城市后，标题变成「在{城市}，今天想去哪逛逛？」，
  下方气泡换成该城市的推荐线路；底部输入框 placeholder 也带城市名。
- **工作台**：进哪个城市就在哪个城市 —— 工具栏显示城市徽标，地图视野与默认酒店切到该城市；
  上海用原来的 276 条 POI 搜索，其它城市左侧变成「{城市} · 添加地点」的地标快捷添加（+ 搜索更多）。
- 城市切换会**清空当前草稿**（避免把上海的点带到北京），并重置天数为 1。

### 限制（必须说清楚）

1. 后端离线快照只有上海 276 条；其它城市是**内置的 6~8 个地标**，够演示但不等于真实城市数据。
2. 其它城市的"搜索更多"用的是同一批地标；要真实搜索需要配 `AMAP_WEB_KEY`（当前 .env 里是空的）。
3. 城市目前是写死的 6 个，加城市只需往 `data/cities.ts` 里加一条。
